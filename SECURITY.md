# Security Policy for Tag

As a solo developer at **Codigo Ciclo**, I take the security and integrity of **Tag** very seriously. This document outlines how to safely report any security vulnerabilities, network exploits, or private Code of Conduct violations.

---

## Supported Versions

Please only report security issues found in the latest official release of the game. Older versions or unauthorized builds are not actively maintained.

| Version | Supported          |
| ------- | ------------------ |
| Latest Release |  Yes |
| Older Versions | ❌ No              |

---

## How to Report a Vulnerability

**Please do not open a public GitHub Issue for a security exploit or severe harassment report.** Publicizing an exploit allows others to abuse it before it can be patched.

Instead, please report vulnerabilities using our secure, private system:

1. Look at the top navigation bar of this repository and click on the **Security** tab.
2. In the left-hand sidebar under "Vulnerability reporting", click **Report a vulnerability**.
3. Detail the exploit, how to replicate it, and any potential impact it has on players or game servers.

This form goes **directly and privately** to me. Your report will remain entirely confidential, and I will review it as quickly as possible.

Thank you for helping keep the **Tag** community safe and secure!
